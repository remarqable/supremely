# Roadmap

Supremely is being built iteratively. This roadmap communicates direction without pretending that early assumptions are permanent.

## Now — v0.1

Establish the first coherent, runnable version of Supremely.

The goal of v0.1 is not completeness. It is to turn the project's thesis and engineering blueprint into working software that can be evaluated honestly.

Success means we have something real enough to use, criticize, change, and build upon.

## Next — v0.2

Let actual experience with v0.1 determine the priorities.

Likely work will include strengthening the core product, removing assumptions that proved wrong, improving developer/user experience, and addressing the first meaningful feedback.

## Toward v1.0

v1.0 should represent confidence rather than a date.

Before calling Supremely 1.0, we expect the core product and architecture to be sufficiently stable that users and contributors can reasonably depend on them.

## What this roadmap is not

It is not a contract.

We expect pivots. We will update this document as we learn.
